# 👩‍💻 Задание для самостоятельной работы: Обработка квадратной матрицы (matrpot)

##  Условие задачи

> Из входного файла (`in.txt`) считывается квадратная матрица размерности `m × m`. Необходимо подсчитать количество **положительных элементов**, расположенных в **нижней треугольной части матрицы (включая главную диагональ)**. Исходную матрицу и найденное количество вывести в выходной файл (`out.txt`).

## ⚙️ Техническая реализация

1.  **Файловые потоки:** Используются `ifstream` для чтения и `ofstream` для записи, с проверкой успешного открытия через `is_open()`.
2.  **Динамическая память:** Для матрицы размерности `m` выделяется память под массив указателей (`int**`), а затем под каждую строку. В конце работы память корректно освобождается.
3.  **Обход треугольной части:** Для подсчёта элементов в нижней треугольной части используется вложенный цикл, где внутренний цикл ограничен условием `j <= i`. 
4.  **Поиск положительных чисел:** В процессе обхода проверяется условие `matr[i][j] > 0`, и при его выполнении счётчик увеличивается.
5.  **Форматированный вывод:** Для красивого вывода матрицы в файл используется манипулятор `setw(2)` из библиотеки `<iomanip>`, что выравнивает столбцы.
