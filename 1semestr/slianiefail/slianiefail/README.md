# 👩‍💻 Задача для самостоятельной работы: Слияние упорядоченных массивов

##  Условие задачи

> Даны два входных файла (`in1.txt` и `in2.txt`), содержащие упорядоченные по возрастанию последовательности целых чисел. Необходимо выполнить слияние (merge) этих данных в единую возрастающую последовательность и записать результат в отдельный выходной файл (`out.txt`).

---

```text
|   ├── in2.txt                  # Второй входной файл

```

##  Техническая реализация

Программа реализует классический алгоритм слияния двух отсортированных массивов без использования дополнительных структур данных в оперативной памяти:

1.  **Файловый ввод-вывод:** Используются потоки `<fstream>` (`ifstream` для чтения, `ofstream` для записи).
2.  **Обработка ошибок:** Каждый файл проверяется на успешное открытие через метод `is_open()`. При ошибке программа выводит сообщение и возвращает код `1`.
3.  **Алгоритм двух указателей:** Числа считываются по одному из каждого файла. Меньшее из двух значений записывается в выходной файл, после чего из этого же файла считывается следующее число.
4.  **Обработка конца файла (Sentinel):** Для контроля окончания данных используется константа `INT_MAX` из библиотеки `<climits>`. Если чтение из файла не удалось (достигнут конец файла), переменная принимает значение `INT_MAX`. Цикл продолжается до тех пор, пока хотя бы один из потоков не исчерпан.
5.  **Закрытие ресурсов:** В конце работы все файловые потоки корректно закрываются методом `close()`.
