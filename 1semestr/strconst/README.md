## 📋 Условие задачи

С клавиатуры вводится **строка длиной не более 100 символов**.

Строка разделена на **слова символами-разделителями**:
- пробел
- запятая `,`
- точка с запятой `;`
- двоеточие `:`

Программа ищет в заданной строке слова, представляющие собой **корректные записи числовых десятичных констант языка C++**.

### Что считается корректной константой

| Пример | Подходит? | Почему |
|--------|-----------|--------|
| `5` | ✅ | целое число |
| `-5` | ✅ | отрицательное целое |
| `+42` | ✅ | целое со знаком `+` |
| `3.14` | ✅ | дробное |
| `-0.5` | ✅ | отрицательное дробное |
| `1e10` | ✅ | экспоненциальная запись |
| `2.5E-3` | ✅ | экспонента с минусом |
| `5f` | ✅ | суффикс `float` |
| `100u` | ✅ | суффикс `unsigned` |
| `3.14L` | ✅ | суффикс `long double` |
| `abc` | ❌ | не число |
| `5.5.5` | ❌ | две точки |
| `1e` | ❌ | экспонента без степени |
| `e5` | ❌ | нет мантиссы |
| `--5` | ❌ | два знака |
| `5-` | ❌ | знак в конце |

## ⚙️ Логика алгоритма

**Основная идея:** разбить строку на **слова** по разделителям и проверить каждое слово — является ли оно **корректной десятичной константой C++**.

### Шаг 1. Разбиение строки на слова

К исходной строке добавляется пробел в конец — это «якорь», чтобы последнее слово тоже корректно находилось:

```cpp
str = str + " ";
string str_not = " ,:;";  // разделители
```

Цикл по всем словам:

```cpp
while ((a = str.find_first_not_of(str_not, a)) != str.npos)
{
    b = str.find_first_of(str_not, a);
    s = str.substr(a, b - a);  // текущее слово
    // ... проверка ...
    a = b;
}
```

### Шаг 2. Проверка слова

Проверка идёт **поэтапно**, отсеивая заведомо неподходящие варианты:

1. **Первый символ** — `+`, `-` или цифра `0..9`.  
   Иначе слово сразу отбрасывается.

2. **Случай длины 1** — одиночная цифра `5`, но **не** `+` или `-`.  
   Такое слово — корректная константа.

3. **Второй символ** (при длине ≥ 2) — цифра, `.`, `e`, `E` или суффикс (`l`, `L`, `u`, `U`, `f`, `F`).  
   Иначе — не константа.

4. **Случай длины 2** — `5L`, `-5`.  
   Если второй символ не `.` — выводим.

5. **Случай длины > 2** — используем `stod(s, &idx)`:
   - `idx == s.length()` → всё слово распознано как число ✅
   - иначе проверяем **суффикс** (`L`, `U`, `F` и т.п.) в позиции `idx`
   - или проверяем **экспоненту** (`e`, `E`) — после неё должно идти корректное число

6. **Проверка экспоненты:**
   - выделяем подстроку после `e`/`E` в `el1`
   - первый символ `el1` — `+`, `-` или цифра
   - если длина 1 — должна быть цифра (не `+`/`-`)
   - если длина ≥ 2 — второй символ цифра
   - `stod(el1, &ide)` и `ide == el1.length()` — всё ок

### Шаг 3. Итог

- если найдена хоть одна константа (`cou > 0`) — она уже выведена в процессе
- если ни одной не найдено → `"There is no correctly written constants!"`
- если строка пустая → `"The line is empty; you haven't entered anything."`

### Используемые строковые функции

| Функция | Что делает |
|---------|------------|
| `getline(cin, s)` | Читает всю строку (с пробелами) |
| `s.empty()` | Проверяет, пустая ли строка |
| `s.find_first_not_of(set, pos)` | Ищет первый символ, **не входящий** в набор |
| `s.find_first_of(set, pos)` | Ищет первый символ **из набора** |
| `s.substr(pos, len)` | Возвращает подстроку |
| `s.length()` | Длина строки |
| `stod(str, &pos)` | Преобразует строку в `double`, `pos` — сколько символов распознано |
| `s.npos` | Спецзначение «не найдено» |
