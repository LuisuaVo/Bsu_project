## 📋 Условие задачи

**Строка состоит из слов, разделённых одним или несколькими пробелами.**

Для слов, состоящих **только из цифр**, найти **сумму отрицательных** и поставить её **в начало строки**.

### Пояснения к условию

- Строка вводится целиком с клавиатуры (с пробелами)
- Слова разделены **одним или несколькими** пробелами
- Рассматриваются только слова, которые **состоят только из цифр** (без букв, точек и т.п.)
- Среди таких слов ищем **отрицательные** (начинающиеся с `-`)
- Вычисляем их **сумму**
- Полученную сумму ставим в **начало строки** и выводим результат
- Если отрицательных чисел нет — выводим соответствующее сообщение

**Примеры слов:**

| Слово | Подходит? | Почему |
|-------|-----------|--------|
| `-5` | ✅ | только цифры + минус, отрицательное |
| `-123` | ✅ | только цифры + минус, отрицательное |
| `5` | ❌ | положительное, не суммируется |
| `-5.5` | ❌ | содержит точку |
| `-1e5` | ❌ | содержит букву |
| `abc` | ❌ | не число |
| `-` | ❌ | минус без цифр |

## ⚙️ Логика алгоритма

**Основная идея:** разбить строку на **слова** (по одному или нескольким пробелам) и проверить каждое слово — является ли оно **отрицательным целым числом**.

### Пошагово

1. **Считываем строку целиком** через `getline(cin, stri)`  
   Обычный `cin >>` остановился бы на первом пробеле, поэтому используем `getline`

2. **Проверяем, что строка не пустая.** Если пустая — выводим сообщение и завершаем

3. **Добавляем в конец строки пробел:** `str = stri + " "`  
   Это технический приём: чтобы `find_first_of` корректно нашёл конец последнего слова

4. **Проходим по всем словам в цикле:**
   - `a = str.find_first_not_of(iskl, a)` — позиция начала слова (пропускаем пробелы)
   - `b = str.find_first_of(iskl, a)` — позиция конца слова
   - `word = str.substr(a, b - a)` — само слово

5. **Проверяем слово** на «отрицательное целое число»:
   - первый символ — цифра `0..9` или `-`
   - если длина `1` — это просто одна цифра (не подходит, кроме случая `-`)
   - если длина `> 1` — второй символ должен быть цифрой
   - `stol(word, &pos)` — конвертируем; `pos` показывает, сколько символов реально распознано
   - если `pos != word.length()` — в слове есть **лишние символы** (буквы, точки) → не число

6. **Дополнительные проверки:**
   - `word.find("e") == npos` — нет экспоненты `e`
   - `word.find("E") == npos` — нет экспоненты `E`
   - `word.find(".") == npos` — не дробное
   - `chis < 0` — действительно отрицательное

7. **Если всё ок** — прибавляем `chis` к `sum` и увеличиваем счётчик `isneg`

8. **В конце:**
   - если найдено хоть одно число → `stri = to_string(sum) + " " + stri`, выводим
   - иначе → сообщение, что отрицательных чисел нет

### Используемые строковые функции

| Функция | Что делает |
|---------|------------|
| `getline(cin, s)` | Читает всю строку (с пробелами) |
| `s.empty()` | Проверяет, пустая ли строка |
| `s.find_first_not_of(set, pos)` | Ищет первый символ, **не входящий** в набор |
| `s.find_first_of(set, pos)` | Ищет первый символ **из набора** |
| `s.find(sub, pos)` | Ищет подстроку |
| `s.substr(pos, len)` | Возвращает подстроку |
| `s.length()` | Длина строки |
| `stol(str, &pos)` | Преобразует строку в `long` |
| `to_string(n)` | Преобразует число в строку |
| `s.npos` | Спецзначение «не найдено» |

## 💻 Примеры работы

### Пример 1 — есть отрицательные числа

```
Please, enter string: abc -5 10 -3.14 -7 e5 -12E4 -42
-54 abc -5 10 -3.14 -7 e5 -12E4 -42
```

**Что произошло:**
- `-5` → ✅ отрицательное, `sum = -5`
- `10` → ❌ положительное
- `-3.14` → ❌ есть точка
- `-7` → ✅ `sum = -12`
- `e5` → ❌ не число
- `-12E4` → ❌ есть `E`
- `-42` → ✅ `sum = -54`
- **Итог:** `sum = -54`, добавляем в начало строки

### Пример 2 — нет отрицательных чисел

```
Please, enter string: hello world 5 10 abc
There are no negative numbers consisted of digit in the row!
```

### Пример 3 — пустая строка

```
Please, enter string:
You haven't entered anything
```
