## 📋 Условие задачи

Написать программу, которая:

- Считывает размер `n` квадратной матрицы с клавиатуры
- Выделяет память под матрицу **динамически** (`new int*[n]` + `new int[n]`)
- Заполняет матрицу **случайными числами** в диапазоне `[0, 20]` с помощью датчика случайных чисел (`srand(time(NULL))` + `rand() % 21`)
- Выводит матрицу на экран в аккуратном форматированном виде (`setw`)
- Вычисляет и выводит **след матрицы** — сумму элементов главной диагонали
- Освобождает выделенную память (`delete[]`)

### Что такое след матрицы

**След (trace)** квадратной матрицы — это сумма элементов, стоящих на **главной диагонали**:

```
trace(A) = a₁₁ + a₂₂ + a₃₃ + ... + aₙₙ
```

Для матрицы:

```
 5  12   3
 7   9   1
 4   6   8
```

След = `5 + 9 + 8 = 22`

## 🔷 Визуализация главной диагонали

```
Матрица (n = 4):

      j=0  j=1  j=2  j=3
i=0    ●    ·    ·    ·       ← mas[0][0]
i=1    ·    ●    ·    ·       ← mas[1][1]
i=2    ·    ·    ●    ·       ← mas[2][2]
i=3    ·    ·    ·    ●       ← mas[3][3]

● — элементы главной диагонали (i == j)
· — остальные элементы (не учитываются)

След = mas[0][0] + mas[1][1] + mas[2][2] + mas[3][3]
```

## 📝 Заметки

- Матрица **квадратная** — количество строк равно количеству столбцов (`n × n`)
- След определён только для квадратных матриц
- Память выделяется динамически и корректно освобождается
- Случайные числа генерируются в диапазоне `[0, 20]` через `rand() % 21`
- Форматированный вывод реализован через `setw(2)` из `<iomanip>`
