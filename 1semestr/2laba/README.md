## 📋 Описание задачи (Вариант 3)

Программа считывает целое число `n`. Если число содержит **нечётное** количество цифр, программа находит центральную цифру и добавляет её в начало и в конец исходного числа. Если количество цифр чётное — число остаётся без изменений.

**Примеры работы:**
*   `123` → `21232` (3 цифры, центральная — `2`)
*   `56789` → `7567897` (5 цифр, центральная — `7`)
*   `42` → `42` (чётное количество цифр, без изменений)
*   `7` → `777` (1 цифра, центральная — `7`)

## 🚀 Как запустить

1. Открыть файл `2laba.slnx` в **Visual Studio**.
2. Собрать решение: `Ctrl + Shift + B`.
3. Запустить программу: `F5`.

**Альтернативный запуск через консоль (g++):**
```bash
g++ -std=c++17 2laba.cpp -o program
./program
```
