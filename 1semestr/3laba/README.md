## 📋 Задание

Написать программу для обработки одномерного массива целых чисел.

### Общие требования

- Использовать **статический массив**
- Максимальную размерность массива задать **именованной константой**
- Реальное количество элементов ввести с клавиатуры **с контролем на выход за границы** массива
- Массив должен состоять **не менее чем из одного элемента**
- Предусмотреть **два способа заполнения** массива:
  - вручную с клавиатуры
  - с помощью датчика случайных чисел (перед заполнением ввести границы интервала `[a, b]`)
- Вывести результаты расчётов
- Если по каким-либо причинам решение задачи **невозможно** — вывести соответствующее сообщение
- **Дополнительные массивы использовать нельзя**
- Для решения **каждой части задачи** написать **отдельную функцию**
- Массив передавать **как параметр**

### Что нужно вычислить и сделать

1. **Минимальный двузначный элемент** массива
2. **Сумму элементов** массива, расположенных **до последнего нулевого** элемента
3. **Преобразовать массив** так, чтобы сначала располагались все элементы с номерами, **кратными 3**, а далее — остальные.  
   Порядок следования элементов **не изменять**

## ⚙️ Функции программы

| Функция | Назначение |
|---------|------------|
| `minEl(int* arr, int n)` | Поиск минимального двузначного элемента массива |
| `sum_do_nul(int* arr, int n)` | Сумма элементов до последнего нулевого элемента |
| `krat(int* arr, int n)` | Перестановка элементов с номерами, кратными 3, в начало массива |
| `get_mass(int* arr, int n)` | Вывод массива на экран |
| `enter_mass_klav(int* arr, int n)` | Ручной ввод элементов массива с клавиатуры |
| `enter_mass_rand(int* arr, int n)` | Заполнение массива случайными числами в диапазоне `[a, b]` |

## 📝 Заметки

- Максимальная размерность массива задана константой `const int MAX = 100;`
- Дополнительные массивы **не используются** — преобразование выполняется перестановками **на месте**
- Если двузначных элементов нет — выводится сообщение `"Net dvyxznach elementov"`
- Если нулевых элементов нет — выводится `"Summ doesn't exist"`
- При `n < 3` массив не преобразуется (переставлять нечего)
- Функция `krat()` использует метод **вставки**: элементы с индексами, кратными 3, "подтягиваются" в начало массива с сохранением относительного порядка
