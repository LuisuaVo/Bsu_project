##  Что такое Unit-тесты

**Unit-тест** — это автоматическая проверка отдельной функции (модуля)
на корректность. Программист заранее записывает: «если на вход подать X,
функция должна вернуть Y». Если реальный результат совпадает с ожидаемым —
тест **пройден**, если нет — **провален**.

**Зачем нужно:**
- Ловит ошибки **сразу**, а не когда программа уже сдана
- Позволяет **безопасно менять код** — если что-то сломается, тест покажет
- Не нужно каждый раз проверять результат **вручную** — всё делает фреймворк

В этом проекте используется **Microsoft Native Unit Test** — встроенный
в Visual Studio фреймворк (`CppUnitTest.h`). Тесты пишутся в виде методов
класса с атрибутами `TEST_CLASS` и `TEST_METHOD`, а проверка выполняется
через `Assert::AreEqual(ожидание, результат)`.

Запуск: **Тест → Обозреватель тестов → Запустить все**.
