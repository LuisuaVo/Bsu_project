## 🇬🇧 English

This folder contains laboratory work and academic projects assigned to 
**first-semester students** in the **Programming** course, written in **C++**.

All assignments were completed as part of the **FAMCS** program at 
**Belarusian State University**, majoring in **Applied Informatics**.

## 🎯 About the Semester

The first semester is all about getting comfortable with the fundamentals of 
programming in C++

## 🛠️ Technologies & Tools

| Tool | Purpose |
|------|---------|
| **C++** | Main programming language |
| **Visual Studio** | Development environment |
| **MSBuild / .slnx** | Project build system |
| **Git** | Version control |

## 🚀 How to Run Any Lab

1. Open the `.slnx` file inside the desired lab folder
2. Build the solution — `Ctrl + Shift + B`
3. Run — `F5`

Or via the console (if a `.cpp` file is present):

```bash
g++ -std=c++17 filename.cpp -o program
./program
```
