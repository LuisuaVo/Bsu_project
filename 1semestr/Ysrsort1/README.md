## 📋 Описание работы

В ходе выполнения лабораторной работы было проведено исследование и сравнение эффективности двух алгоритмов сортировки:
1. **Чётно-нечётная сортировка** (Odd-Even Sort) — модификация пузырьковой сортировки.
2. **Сортировка расчёской** (Comb Sort) — улучшенная версия пузырьковой сортировки, использующая уменьшающийся шаг.

## ⚙️ Метрики сравнения

Программа генерирует массивы заданного размера (случайные, по возрастанию или по убыванию) и фиксирует для каждого алгоритма:
* **Время выполнения** (в секундах и миллисекундах с использованием библиотеки `<chrono>`).
* **Количество операций сравнения** элементов.
* **Количество операций обмена** (перестановок) элементов.

Результаты всех замеров были занесены в прикрепленную Excel-таблицу для дальнейшего построения графиков и анализа.

## 🚀 Как запустить

1. Открыть файл `project.slnx` в **Visual Studio**.
2. Собрать решение: `Ctrl + Shift + B`.
3. Запустить программу: `F5`.
4. Ввести размер массива и способ его заполнения (для `n = 10` доступен ручной ввод).
