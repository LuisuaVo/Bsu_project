## 📋 Условие задачи

Написать программу, которая:

- Считывает с клавиатуры **целое число** `n`
- Проверяет, является ли оно **палиндромом**
- Выводит соответствующее сообщение

**Палиндром** — число, которое читается одинаково слева направо и справа налево.  
Например: `121`, `1331`, `7`, `0`, `555`.

## 📝 Как это работает

Идея алгоритма — **перевернуть число** и сравнить его с исходным:

1. Запоминаем исходное значение в переменной `k`
2. В цикле «собираем» перевёрнутое число в переменной `m`:
   - берём последнюю цифру `n % 10`
   - «сдвигаем» уже собранное число влево (`m * 10`) и добавляем цифру
   - отбрасываем последнюю цифру исходного числа (`n / 10`)
3. Когда `n` обнулится — в `m` лежит перевёрнутое число
4. Сравниваем `k == m`:
   - равны → палиндром
   - не равны → не палиндром

**Пример пошагово (n = 1331):**

| Итерация | n | m |
|----------|---|---|
| старт | 1331 | 0 |
| 1 | 133 | 1 |
| 2 | 13 | 13 |
| 3 | 1 | 133 |
| 4 | 0 | 1331 |

`k = 1331`, `m = 1331` → **палиндром** ✅
