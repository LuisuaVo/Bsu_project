## Техническая реализация

Программа демонстрирует продвинутую работу со строками и файловыми потоками:

1.  **Файловый ввод-вывод:** Используется `ifstream` для чтения `input.txt` с проверкой успешного открытия. 
2.  **Вспомогательная функция `lengpunct`:** Разбивает строку на слова с помощью `find_first_not_of` и `substr`, а затем ищет в каждом слове самую длинную цепочку символов, принадлежащих заданному пользователем множеству (через `find_first_of` и `find_first_not_of`).
3.  **Оптимизация памяти:** Программа не сохраняет весь файл в оперативную память. После первого прохода (поиска максимума) она использует `seekg(0)` и `clear()` для возврата в начало файла и выводит только нужные строки, не создавая дополнительных массивов.
4.  **Безопасность ввода:** Защита от пустого ввода пользователя и пустых строк в файле.
