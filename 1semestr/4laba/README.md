# 👩‍💻Лабораторная работа №4 по теме **"Матрицы"**

Написать программу, которая:

1. Считывает размер `n` квадратной матрицы
2. Заполняет матрицу двумя способами на выбор:
   - вручную с клавиатуры
   - случайными числами в заданном диапазоне `[a, b]`
3. Находит **максимальный элемент** в верхнем треугольнике матрицы (область `j ≥ i`, включая главную диагональ)
4. Сортирует строки матрицы:
   - **чётные строки** — по возрастанию
   - **нечётные строки** — по убыванию
5. Выводит исходную и преобразованную матрицу

## ⚙️ Функции программы

| Функция | Назначение |
|---------|------------|
| `enter_mass_klav(int** arr, int n)` | Ручной ввод элементов матрицы с клавиатуры |
| `enter_mass_rand(int** arr, int n)` | Заполнение матрицы случайными числами в диапазоне `[a, b]` |
| `get_mass(int** arr, int n)` | Вывод матрицы на экран |
| `maxelvp(int** arr, int n)` | Поиск максимального элемента в области `j ≥ i` |
| `sortvozr(int* arr, int n)` | Сортировка строки по возрастанию |
| `sortub(int* arr, int n)` | Сортировка строки по убыванию |

## 📝 Заметки

- Память под матрицу выделяется динамически (`new int*[n]` + `new int[n]`) и корректно освобождается (`delete[]`)
- Использован классический пузырьковый метод сортировки
- Случайные числа: `srand(time(NULL))` + `rand() % (b - a + 1) + a`
- Форматирование вывода через `setw(3)` из `<iomanip>`
