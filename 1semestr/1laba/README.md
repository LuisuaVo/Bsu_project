## 📋 Условие задачи

Вычислить приближённое значение функции, используя представление её в виде **ряда Тейлора**.

Вычисления заканчивать, когда очередное слагаемое окажется **по модулю меньше** заданного числа `ε`, где `0 < ε < 10⁻ᵏ`, `k` — натуральное число, `k > 1`.

**Сравнить** полученный результат со значением, вычисленным с помощью **стандартной функции**.

Значения `x` и `ε` ввести по запросу.

### Вариант — функция sin(x)

```
sin(x) = x - x³/3! + x⁵/5! - x⁷/7! + ...
```

где `x ∈ (-∞, +∞)`

## ⚙️ Логика алгоритма

Разложение `sin(x)` в ряд Тейлора:

```
sin(x) = x - x³/3! + x⁵/5! - x⁷/7! + ...
```

**Ключевая идея:** каждое следующее слагаемое получается из предыдущего **рекуррентно**:

```
aₙ₊₁ = -aₙ · x² / ((n+1)(n+2))
```

Это позволяет **не считать факториалы напрямую** — они быстро переполняют типы данных. Вместо этого мы каждый раз «достраиваем» новое слагаемое из предыдущего.

**Переменные:**

| Переменная | Назначение |
|------------|------------|
| `e` | заданная точность ε |
| `x` | аргумент функции |
| `sinx` | накопленная сумма ряда (наш результат) |
| `a` | текущее слагаемое |
| `n` | номер текущего нечётного члена (1, 3, 5, ...) |

**Пошагово:**

1. Вводим `ε` и `x`
2. Первое слагаемое `a = x`
3. Пока `|a| > ε`:
   - добавляем `a` к сумме `sinx`
   - вычисляем следующее слагаемое через рекуррентную формулу
   - увеличиваем `n` на 2
4. Выводим:
   - значение, посчитанное через ряд
   - значение стандартной функции `sin(x)` из `<cmath>`
   - **разницу** между ними

## 💻 Пример работы

```
Enter gr e, x: 0.0001 1.5
sin(x)=0.997495
std sin(x)      = 0.997495
Difference      = 8.88179e-07
```

**Что здесь происходит:**
- `sinx` — сумма ряда Тейлора ≈ `0.997495`
- `sin(x)` — стандартная функция из `<cmath>` ≈ `0.997495`
- `Difference` — разница между ними ≈ `8.88·10⁻⁷`

Разница **намного меньше** заданной точности `ε = 0.0001`, что подтверждает корректность вычислений ✅
